# Règles de la Belote 1v1

La Belote 1v1 est un jeu de plis pour deux joueurs. Chaque main a une couleur d'atout. Les joueurs gagnent des plis, collectent des points de cartes, marquent des annonces, puis ajoutent le score de la main à leur total. La partie se joue jusqu'à ce qu'un joueur atteigne 501 points.

## Jeu de cartes

Le jeu utilise 32 cartes :

- Couleurs : Glands, Grelots, Coeurs, Feuilles
- Rangs : VII, VIII, IX, X, U/V, O/D, K/R, A

## Objectif

Après chaque main, les scores sont ajoutés aux totaux des joueurs.

Le premier joueur qui atteint au moins 501 points gagne. Si les deux joueurs atteignent 501 dans la même main, le total le plus élevé gagne. Si les totaux sont à égalité, la partie continue jusqu'à ce qu'un joueur soit devant.

## Donneur et premier joueur

Le premier donneur est choisi au hasard. Le donneur change après chaque main.

Le non-donneur est le premier joueur de la main. Le premier joueur :

- Décide en premier pendant le choix de l'atout
- Entame le premier pli
- Doit choisir l'atout si la main arrive au mus

## Distribution

Au début de chaque main :

- Chaque joueur reçoit 8 cartes.
- Chaque joueur reçoit aussi 2 cartes cachées à ramasser.
- Une carte est retournée face visible.
- Le reste du paquet reste inutilisé pour cette main.

Après le choix de l'atout, chaque joueur ramasse ses 2 cartes cachées, donc chaque joueur joue avec 10 cartes.

La carte retournée sert uniquement au choix de l'atout. Elle n'est pas jouée, ne peut pas être annoncée et n'est pas échangée contre le VII d'atout.

## Choix de l'atout

L'atout est choisi en trois étapes au maximum.

1. Premier tour : le premier joueur, puis le second joueur, peuvent accepter la couleur de la carte retournée comme atout.
2. Deuxième tour : si les deux passent, le premier joueur, puis le second joueur, peuvent choisir n'importe quelle couleur sauf celle de la carte retournée.
3. Mus : si les deux passent encore, le premier joueur doit choisir n'importe quelle couleur sauf celle de la carte retournée.

Le joueur qui choisit l'atout est le preneur.

## Force des cartes et points

Cartes hors atout, de la plus forte à la plus faible :

| Rang | Points |
| --- | ---: |
| A | 11 |
| X | 10 |
| K/R | 4 |
| O/D | 3 |
| U/V | 2 |
| IX | 0 |
| VIII | 0 |
| VII | 0 |

Cartes d'atout, de la plus forte à la plus faible :

| Rang | Points |
| --- | ---: |
| U/V | 20 |
| IX | 14 |
| A | 11 |
| X | 10 |
| K/R | 4 |
| O/D | 3 |
| VIII | 0 |
| VII | 0 |

Le gagnant du dernier pli reçoit 10 points de cartes supplémentaires.

## Annonces

Les annonces sont marquées après le choix de l'atout et avant le jeu des plis. Le jeu applique, pour chaque joueur, l'ensemble valide d'annonces non chevauchantes qui rapporte le plus de points. Les cartes annoncées sont montrées aux deux joueurs, mais restent dans la main du joueur jusqu'à ce qu'elles soient jouées.

### Belote

Le K/R d'atout et le O/D d'atout ensemble valent 20 points.

### Suites

Une suite contient au moins 3 cartes consécutives de la même couleur, dans cet ordre :

VII, VIII, IX, X, U/V, O/D, K/R, A

| Suite | Points |
| --- | ---: |
| 3 cartes | 20 |
| 4 cartes | 50 |
| 5 cartes ou plus | 100 |

### Carrés

| Annonce | Points |
| --- | ---: |
| Quatre U/V | 200 |
| Quatre IX | 150 |
| Quatre A | 100 |
| Quatre X | 100 |
| Quatre K/R | 100 |
| Quatre O/D | 100 |

Quatre VII et quatre VIII ne marquent pas.

Une carte ne peut servir que dans une seule annonce ordinaire, c'est-à-dire une suite ou un carré. La belote est l'exception : le K/R d'atout et le O/D d'atout peuvent aussi faire partie d'une annonce ordinaire.

## Jeu des plis

Chaque main a 10 plis. Le premier joueur entame le premier pli. Ensuite, le gagnant de chaque pli entame le suivant.

Quand vous répondez à un pli :

- Si vous avez la couleur demandée, vous devez jouer cette couleur.
- Si vous n'avez pas la couleur demandée mais avez de l'atout, vous devez jouer atout.
- Si vous n'avez ni la couleur demandée ni atout, vous pouvez jouer n'importe quelle carte.

Si un atout est joué, l'atout le plus fort gagne le pli. Sinon, la carte la plus forte dans la couleur demandée gagne.

## Score de la main

Chaque joueur compte d'abord :

- Les points de cartes des plis gagnés, y compris le bonus de 10 points du dernier pli s'il l'a gagné
- Les points d'annonces

Le preneur réussit seulement si son total est supérieur au total adverse. Une égalité signifie que le preneur chute.

Si le preneur réussit, les deux joueurs marquent leurs propres totaux pour la main.

Si le preneur chute :

- Si le preneur a quand même plus de points de cartes que l'adversaire, le preneur marque 0 et l'adversaire marque son propre total.
- Si le preneur a autant ou moins de points de cartes, le preneur marque 0 et l'adversaire marque les totaux des deux joueurs.
- Si la main était au mus et que le preneur a autant ou moins de points de cartes, le preneur marque -20 et l'adversaire marque seulement son propre total.

## Schuster

Un joueur qui ne gagne aucun pli dans une main est schuster.

Ses points d'annonces ne comptent pas pour lui ; ils sont donnés à l'autre joueur. Le joueur schuster reçoit aussi -100 points supplémentaires pour la main. Les scores totaux peuvent descendre sous zéro.
