# Hungarian card images

The 32 card-face images in this directory were cropped from:

- File: Doppeldeutsche Preference.JPG
- Source: https://commons.wikimedia.org/wiki/File:Doppeldeutsche_Preference.JPG
- Original file: https://upload.wikimedia.org/wikipedia/commons/6/64/Doppeldeutsche_Preference.JPG
- Author: FUZxxl, with the current Commons version contrast-enhanced by Karl432
- License: Creative Commons Attribution 3.0 Unported, https://creativecommons.org/licenses/by/3.0/

The cropped images are adapted from the original Commons file. The VI/Weli
column from the 36-card source deck is intentionally excluded so GreaterCard
uses the 32-card Hungarian deck: VII, VIII, IX, X, Unter, Ober, King, Ace in
Acorns, Bells, Hearts, and Leaves.
