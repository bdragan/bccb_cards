# Belot 1v1 Rules

Belot 1v1 is a two-player trick-taking card game. Each hand has one trump suit. Players win tricks, collect card points, score declarations, and add the hand score to their total. The game is played until a player reaches 501 points.

## Deck

The game uses 32 cards:

- Suits: Acorns, Bells, Hearts, Leaves
- Ranks: VII, VIII, IX, X, U/J, O/Q, K, A

## Goal

After each hand, scores are added to the players' totals.

The first player to reach at least 501 points wins. If both players reach 501 in the same hand, the higher total wins. If the totals are tied, play continues until one player is ahead.

## Dealer and First Player

The first dealer is chosen randomly. The dealer changes after every hand.

The non-dealer is the first player for the hand. The first player:

- Decides first during trump selection
- Leads the first trick
- Must choose trump if the hand reaches mus

## Deal

At the start of each hand:

- Each player receives 8 cards.
- Each player also receives 2 hidden pickup cards.
- One card is turned face up as the upcard.
- The rest of the deck stays unused for that hand.

After trump is chosen, each player picks up their 2 hidden cards, so each player plays with 10 cards.

The upcard is only used for trump selection. It is not played, cannot be declared, and is not exchanged for the trump VII.

## Trump Selection

Trump is chosen in up to three steps.

1. First round: the first player, then the second player, may accept the upcard suit as trump.
2. Second round: if both pass, the first player, then the second player, may choose any suit except the upcard suit.
3. Mus: if both pass again, the first player must choose any suit except the upcard suit.

The player who chooses trump is the caller.

## Card Strength and Points

Non-trump cards, strongest to weakest:

| Rank | Points |
| --- | ---: |
| A | 11 |
| X | 10 |
| K | 4 |
| O/Q | 3 |
| U/J | 2 |
| IX | 0 |
| VIII | 0 |
| VII | 0 |

Trump cards, strongest to weakest:

| Rank | Points |
| --- | ---: |
| U/J | 20 |
| IX | 14 |
| A | 11 |
| X | 10 |
| K | 4 |
| O/Q | 3 |
| VIII | 0 |
| VII | 0 |

The winner of the last trick gets 10 extra card points.

## Declarations

Declarations are scored after trump is chosen and before trick play begins. The game applies the highest-scoring valid set of non-overlapping declarations for each player. Declared cards are shown to both players, but they stay in the player's hand until played.

### Belote

The trump K and trump O/Q together score 20 points.

### Sequences

A sequence is 3 or more consecutive cards in the same suit, using this order:

VII, VIII, IX, X, U/J, O/Q, K, A

| Sequence | Points |
| --- | ---: |
| 3 cards | 20 |
| 4 cards | 50 |
| 5 or more cards | 100 |

### Four of a Kind

| Declaration | Points |
| --- | ---: |
| Four U/J | 200 |
| Four IX | 150 |
| Four A | 100 |
| Four X | 100 |
| Four K | 100 |
| Four O/Q | 100 |

Four VII and four VIII do not score.

A card can be used in only one ordinary declaration, meaning one sequence or four-of-a-kind. Belote is the exception: the trump K and trump O/Q may also be part of one ordinary declaration.

## Trick Play

Each hand has 10 tricks. The first player leads the first trick. After that, the winner of each trick leads the next one.

When responding to a trick:

- If you have the lead suit, you must play that suit.
- If you do not have the lead suit but have trump, you must play trump.
- If you have neither the lead suit nor trump, you may play any card.

If any trump is played, the strongest trump wins the trick. Otherwise, the strongest card in the lead suit wins.

## Hand Scoring

Each player first counts:

- Card points from won tricks, including the 10-point last-trick bonus if won
- Declaration points

The caller succeeds only if the caller's total is higher than the opponent's total. A tie means the caller falls.

If the caller succeeds, both players score their own totals for the hand.

If the caller falls:

- If the caller still has more card points than the opponent, the caller scores 0 and the opponent scores their own total.
- If the caller has equal or fewer card points, the caller scores 0 and the opponent scores both players' totals.
- If the hand was mus and the caller has equal or fewer card points, the caller scores -20 and the opponent scores only their own total.

## Schuster

A player who wins no tricks in a hand is schuster.

That player's declaration points do not count for them; they are given to the other player instead. The schuster player also gets an extra -100 points for the hand. Total scores can go below zero.
